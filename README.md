# MEDILAB — Medical Laboratory Report Management System

**MEDILAB** is a native Android application built with **Kotlin** and **Jetpack Compose** for managing medical laboratory workflows. It streamlines patient record management, diagnostic test tracking, local SQLite CRUD operations, and automated PDF lab report generation.

---

## Features

- **Patient Management**: Add, update, search, and maintain structured patient profiles.
- **Diagnostic Test Records**: Log and manage laboratory test results with full local SQLite CRUD support.
- **PDF Report Generation**: Generate and export clean, shareable diagnostic lab reports in PDF format.
- **AI-Assisted Capabilities**: Integrated with the Gemini API for enhanced report handling and assistance.
- **Modern Android UI**: Built with Jetpack Compose for a responsive, clean clinical interface.

---

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Local Storage**: SQLite (with KSP annotation processing)
- **AI Integration**: Google Gemini API
- **Build System**: Gradle (Kotlin DSL) with Secrets Gradle Plugin
- **Testing**: Roborazzi screenshot testing

---

## Prerequisites

- [Android Studio](https://developer.android.com/studio) (latest stable version recommended)
- JDK 17+
- Android Emulator or physical Android device
- A valid **Gemini API Key**
